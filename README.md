A simple Python program to check whether a number is even or odd .
Even Odd Checker

A simple Even Odd Checker built using HTML, CSS, and JavaScript. This application allows users to enter a number and instantly check whether it is even or odd.

Features

- Check if a number is even or odd
- Instant result display
- Simple and user-friendly interface
- Responsive design
- Beginner-friendly project

Technologies Used

- HTML
- CSS
- JavaScript

How to Use

1. Open the application in your browser.
2. Enter a number in the input field.
3. Click the Check button.
4. View the result instantly.

This project helped me practice:

- JavaScript Functions
- Conditional Statements (if-else)
- DOM Manipulation
- User Input Handling
- Event Handling
